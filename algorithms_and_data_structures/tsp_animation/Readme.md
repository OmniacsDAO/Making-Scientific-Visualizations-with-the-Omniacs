# 🧭 Traveling Salesman Problem Visualization (Manim)

This animated project brings the **Traveling Salesman Problem (TSP)** to life using [Manim](https://www.manim.community/). It blends cinematic storytelling with algorithmic intuition — illustrating the complexity, brute force limitations, greedy strategies, route optimization, and real-world impact.

## 🧩 What You'll Learn

### 🎬 Scenes Included:
- **Dramatic Intro** — Cinematic title reveal
- **Problem Setup** — Cities, salesman, and sample routes
- **Complexity Explosion** — How factorial permutations scale
- **Algorithm Battle** — Brute Force vs Nearest Neighbor
- **Optimization** — Fixing crossings and improving distance
- **Real-World Applications** — Logistics, manufacturing, and genomics

### ⚙️ Techniques Visualized:
- Permutation growth
- Greedy vs exhaustive search
- Route distance calculation
- 2-opt optimization
- Visual storytelling with Manim

## 📦 Requirements

- Python 3.7+
- [Manim Community Edition](https://docs.manim.community/en/stable/)

Install Manim:

```bash
pip install manim
```

🚀 How to Render


manim -pql tsp_animation.py TSPAnimation

Use -pqh or -p4k for higher quality output.

📁 Files

    tsp_animation.py — Full Manim script
    TSPVisualization.mp4 — Rendered animation (optional)
    preview.gif — Thumbnail animation for README or social sharing
