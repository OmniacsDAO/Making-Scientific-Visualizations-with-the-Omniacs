# Educational Shape Evolution — Learn Manim Through Shapes

<img width="2807" height="1554" alt="image" src="https://github.com/user-attachments/assets/906272a5-3f68-417e-aa15-af9e29a5e10e" />

This visualization uses **Manim** to teach geometry, transformations, and animation concepts by evolving basic shapes into detailed, real-world objects. Along the way, annotated code snippets are displayed so you can connect each transformation to the underlying Python commands.

Watch [here](https://www.youtube.com/watch?v=GB6dQNnC3Do).
---

## 🎥 What the Visualization Covers

- **Triangle → Mountain Scene**  
  A simple triangle becomes a full mountain landscape with snow caps and pine trees.  

- **Hexagon → Flower**  
  A polygon blossoms into a realistic flower with petals, stamens, and leaves.  

- **Star → Starfish**  
  A star transforms into a textured starfish with ridges and details.  

- **Pentagon → Medieval Shield**  
  A polygon evolves into a shield complete with border, cross, studs, and a banner.  

- **Bonus: Bicycle Construction**  
  Shapes combine to build a detailed bicycle, step by step — wheels, spokes, frame, handlebars, and more:contentReference[oaicite:1]{index=1}.  

- **Final Recap**  
  Concludes with a message highlighting the Manim concepts learned: polygons, transformations, grouping, and animation.

## ▶️ Running the Animation

To render the visualization locally:

```bash
# Install dependencies
pip install manim

# Render with preview (high quality)
manim -pqh educational_shape_evolution.py EducationalShapeEvolution
```
