# Shape Story Animation — Creative Geometry with Manim

<img width="2546" height="1599" alt="image" src="https://github.com/user-attachments/assets/52ef154b-ebbb-4e07-b78c-baf34f7d902e" />

This visualization uses **Manim** to turn simple shapes into everyday objects while showing short code annotations along the way. You’ll see a circle become a **sun**, an oval turn into an **eye**, a square transform into a **clock**, and a triangle morph into a **hat**—before everything comes together to **build a house** from first principles.

Watch [here](https://www.youtube.com/watch?v=S_gqfjMfiNs).
---

## 🎥 What the Visualization Covers

- **Circle → Sun**  
  A glowing circle sprouts animated rays using a simple loop and line primitives.

- **Oval → Eye**  
  Layered circles (iris, pupil, specular highlight) demonstrate grouping and positioning.

- **Square → Clock**  
  A square becomes a clock face with hands, numerals, and a center cap to practice alignment and layering.

- **Triangle → Hat**  
  A triangle, brim ellipse, band rectangle, and small details show constructive “kitbashing” with basic shapes.

- **Final Scene: Build a House**  
  Roof (triangle), walls (rectangle), door + knob, window panes, clouds, and a sun in the sky—an end-to-end example of composition and scene layout.

> The animation includes concise, on-screen code snippets for each step so learners can connect visuals to the exact Manim calls.

## ▶️ Running the Animation

```bash
# Install dependencies
pip install manim

# Render with preview (high quality)
manim -pqh shapestoryanimation.py ShapeStoryAnimation
```

✨ Learning Outcomes

Using primitive mobjects (Circle, Square, Ellipse, Line, Polygon)

Grouping with VGroup for organized transforms

Transforms & animations (Create, Transform, FadeIn/Out, Write)

Layout techniques (next_to, move_to, to_edge, shift)

Readable code overlays to reinforce each modeling step
