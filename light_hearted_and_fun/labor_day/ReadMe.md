🎇 Honoring American Workers — Fireworks Visualization

This Manim animation pays tribute to American workers with a dazzling fireworks display in patriotic red, white, and blue. The animation layers multiple waves of fireworks, builds toward a grand finale, and even includes a code demo showing how the firework effects are created.

🎥 What You’ll See

A night sky filled with glowing stars
Sequential waves of fireworks bursting across the scene
A patriotic finale of red, white, and blue sparks
A behind-the-scenes code demo showing how the fireworks were built


🛠️ Requirements

Python 3.8+
Manim Community Edition
SciPy
NumPy

```
pip install manim numpy scipy
```

▶️ How to Run

```
manim -pql Lorenz_attractor.py HonoringAmericanWorkers
```

Use -qh for high-quality rendering.
