# 🌊 Wave Interference Animation with Manim

This project uses [Manim](https://www.manim.community/) to beautifully visualize **wave interference phenomena** — showing how two waves traveling in opposite directions interact to form standing waves, constructive and destructive patterns, and more.

## 📽️ Demo Output

*A dynamic visualization of two interacting waves demonstrating key physics principles.*

## 📦 Requirements

- Python 3.7+
- [Manim Community Edition](https://docs.manim.community/en/stable/)

Install with:

```bash
pip install manim
```

🚀 How to Run

manim -pql wave_interference.py WaveInterference

Use -pqh or -p4k for high-quality rendering.

🧪 Animation Features
🔹 Concepts Visualized

    Traveling Waves: Two sine waves propagating in opposite directions
    Superposition: Real-time animation of wave addition
    Constructive Interference: Waves in phase amplify each other
    Destructive Interference: Opposite phase waves cancel out
    Standing Waves: Resulting pattern with nodes and antinodes

🎨 Visual Enhancements

    Color-coded wave components
    Smooth animations with time tracking
    Titles, labels, and captions for clarity
    Final summary and credit scene

📁 Files
